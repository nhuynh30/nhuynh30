### 🔭 Featured Projects

#### 🏃 [PaceTrack](https://github.com/nhuynh30)
Full-stack running tracker with real-time club leaderboards, GPS route ingestion, and interactive route maps.
`React.js` `Node.js` `Express.js` `MongoDB` `Socket.io` `AWS S3` `Mapbox GL JS`
- Real-time leaderboard sync via Socket.io rooms across concurrent client sessions
- GPS route pipeline with S3 presigned uploads, GPX parsing, and haversine distance/elevation analytics
- Interactive Mapbox route rendering with GeoJSON LineStrings and live-run playback

#### 📈 [TradingLab](https://github.com/nhuynh30)
Portfolio backtesting and AI-assisted investment platform for BTC, ETH, AAPL, and TSLA simulations.
`React.js` `TypeScript` `NestJS` `MongoDB` `Redis` `OpenAI API` `Docker`
- Multi-asset DCA portfolio workflow with weight-allocation validation
- AI advisor streaming real-time insights via OpenAI API, SSE, and Redis-backed rate limiting

#### 🛒 [OpenCart](https://github.com/nhuynh30)
Full-stack multi-vendor marketplace with separate buyer/seller experiences and integrated payments.
`Next.js` `TypeScript` `PostgreSQL` `Prisma` `Redis` `Stripe Connect` `NextAuth` `AWS S3`
- Stripe Connect integration for seller onboarding with automatic split payments and webhook reconciliation
- Redis-cached seller payout dashboard and real-time buyer-seller chat with review system
